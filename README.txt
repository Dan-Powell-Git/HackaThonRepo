Skills-Based Returnship Program: Hackathon Plan
A starting plan for building a skills-based returnship platform during a hackathon.
Core Idea
A platform where returners (parents, caregivers, and anyone who took a career break) show their skills, including ones gained during the break, and get matched to returnship roles. The platform also gives them a personalized plan to close any skill gaps.
MVP Features
Build these during the hackathon:
Profile and skills input: The user uploads a CV or types in past roles, and adds break-time experience such as caregiving, volunteering, freelancing, and courses.
Skill extraction: An AI model turns the text into a structured skills list, including transferable skills like budgeting, project management, and negotiation.
Returnship matching: Compare the user's skills to the skills required by returnship listings and show a match score.
Skill gap and learning plan: Show missing skills with suggested free courses and a 4-8 week refresh roadmap.
Employer view (optional): Companies post returnships and see ranked candidates.
Suggested Tech Stack
Frontend: React or Next.js (or plain HTML if you are short on time)
Backend: Python (FastAPI) or Node.js
AI: An LLM API for skill extraction and gap analysis
Data: A simple JSON or SQLite file with sample returnship listings, which is fine for a demo
Hackathon Timeline (24-48 hours)
Hours 0-3: Decide the problem, target user, and demo story
Hours 3-10: Build skill extraction and matching (the "wow" feature)
Hours 10-18: Build the UI and the learning plan
Hours 18-22: Add polish, sample data, and a smooth demo flow
Last hours: Prepare a 3-minute pitch covering the problem, the demo, and the impact
Pitch Angle
Millions of skilled people, many of them women, leave the workforce and struggle to return because CVs don't show their real skills. This tool makes those skills visible and connects them to opportunities.
